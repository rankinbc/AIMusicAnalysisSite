# analysis

**Purpose**: Self-contained Python package containing all 7-phase audio analysis pipeline modules, adapted from the existing AbletonAIAnalysis project. Installed as an editable package so `api` and `worker` can import from it. Exposes a single entry point: `run_pipeline(file_path, reference_path=None, progress_cb=None)` that runs all phases sequentially and returns a structured dict. Phases: (1) universal mix analysis — LUFS/loudness, 7-band frequency balance, stereo health, transient analysis, BPM; (2) genre auto-detection; (3) genre-specific scoring (trance/house/techno/dnb); (4) stem separation + clash detection via Demucs htdemucs_ft; (5) reference track comparison; (6) genre profile gap analysis vs curated reference library; (7) arrangement advisor.

**Inputs**: `data/uploads/` (audio files), `data/reference_library/` (curated pro reference tracks by genre), `data/models/` (cached ML weights)

**Outputs**: `output/analysis_results/` (per-job JSON)

**Pattern**: `analysis.md`

**Stack**: Python 3.11+ — librosa, pyloudnorm, soundfile, torch, demucs, torchopenl3, all-in-one-fix, numpy<2.0

## How to run

```bash
# Install editable from project root
pip install -e components/analysis

# Verify package is importable
python -c "from audio_analysis import run_pipeline; print(run_pipeline('data/uploads/test.wav'))"

# Run tests
pytest components/analysis/tests/
```

## Windows note

Phase 7 (arrangement advisor) uses `all-in-one-fix`, which depends on NATTEN. NATTEN has no Windows wheels. Run phase 7 inside Docker or WSL2 on Windows hosts. Phases 1-6 run natively on Windows.

## Structure

```
components/analysis/
├── pyproject.toml              # hatchling build — pip install -e installs src/audio_analysis
├── .env.example                # TORCH_HOME=data/models
├── src/
│   └── audio_analysis/
│       ├── __init__.py         # exports run_pipeline
│       ├── pipeline.py         # orchestrator — run_pipeline() entry point
│       ├── schemas.py          # TypedDicts for PipelineResult, PhaseResult
│       ├── models.py           # singleton model loader — get_model(name)
│       ├── converters.py       # normalises any audio → 44100 Hz WAV before pipeline
│       └── phases/
│           ├── phase1_universal.py     # LUFS, 7-band EQ, stereo, BPM
│           ├── phase2_genre.py         # genre detection via torchopenl3
│           ├── phase3_genre_specific.py# per-genre scoring rubric
│           ├── phase4_stems.py         # demucs htdemucs_ft + clash detection
│           ├── phase5_reference.py     # reference track delta comparison
│           ├── phase6_gap.py           # gap analysis vs reference library
│           └── phase7_arrangement.py   # arrangement sections + advice
└── tests/
    ├── test_pipeline.py        # stub — /execute-prp writes real tests
    └── fixtures/               # synthetic test audio generated by pytest fixtures
```
