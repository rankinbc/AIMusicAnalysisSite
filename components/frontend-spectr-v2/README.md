# frontend-spectr-v2 — React 19 + TypeScript SPA

Single-page app. Talks only to the C# BFF at `/api/*`. Vite dev server runs
at `http://localhost:5174` and proxies `/api/*` to the BFF at
`http://localhost:5000`.

## Stack

- **Build:** Vite 6
- **Language:** TypeScript (strict, `verbatimModuleSyntax`)
- **Routing:** TanStack Router (file-based, code-split, typed)
- **Server state:** TanStack Query
- **Validation:** Zod (schemas generated from BFF OpenAPI via `orval`)
- **UI primitives:** Radix UI (à la carte)
- **Audio:** WaveSurfer.js v7
- **Charts:** Recharts
- **Toasts:** Sonner
- **Drag/drop:** dnd-kit
- **Chat:** Vercel AI SDK
- **Styling:** CSS Modules + `tokens.css`
- **Test:** Vitest (unit), Playwright (E2E)

No Tailwind. No styled-components. No MUI/Chakra/Mantine. Custom audio-tool
aesthetic.

## Local dev

```bash
npm install
npm run dev
```

The BFF must be running on port 5000 for `/api/*` to resolve.

## Generated artifacts

- `src/routeTree.gen.ts` — generated by the TanStack Router vite plugin from
  `src/routes/**`. Don't edit by hand.
- `src/api/generated/**` — generated by orval from `openapi.json` (which the
  BFF emits). Run `npm run gen-types` after the BFF schema changes.

## Routing structure

```
/                          → redirect to /library
/_public/login             public layout
/_public/r/$token          public share-link reviewer
/_app/library              authed layout
/_app/songs/$songId
/_app/songs/$songId/results/$jobId
/_app/listen/$versionId
/_app/profile
/_app/coach/$jobId
/_app/compare
/_app/discover             (Phase 4 — deferred)
```
