# reference_library inputs

Curated professional reference tracks organized by genre. Consumed by: analysis (phases 5–6: reference comparison and genre profile gap analysis).

## Structure

Place reference tracks in the appropriate genre subfolder:
- `trance/`   — 20–50 professionally mastered trance tracks
- `house/`    — 20–50 professionally mastered house tracks
- `techno/`   — 20–50 professionally mastered techno tracks
- `dnb/`      — 20–50 professionally mastered drum & bass tracks
- `other/`    — tracks that don't fit the above genres

Supported formats: WAV, MP3, FLAC, AIFF. Higher quality (WAV/FLAC) gives more accurate reference profiles.
