# SPECTR BFF API Contracts

Component: `components/bff/src/Spectr.Bff/Endpoints/` — generated by BMAD document-project deep
scan, 2026-07-22. Source of truth: the `*Endpoints.cs` files named per group (~198 mapped routes).
The legacy FastAPI service (`components/api/`) still exists but is being phased out and is not
documented here.

## Conventions

- **Prefix**: all app routes mount under `/api` (`Program.cs` `app.MapGroup("/api")`). Exceptions
  mapped at root: crawler shells (`/`, `/pricing`, `/analyze`, `/trust/*`, `/r/{token}`),
  `/healthz`, `/metrics`, and `POST /api/email/webhook` (mapped on `app` with explicit prefix).
- **Error envelope** (AR38, `Endpoints/ErrorEnvelope.cs`): `{ "error": { "code", "message",
  "details" } }`. Clients key off `code`, never `message`. Unhandled exceptions → 500
  `internal_error` with `details.traceId`. Some older validation branches still return plain
  `{ "error": "text" }` 400s (~120 sites across 18 endpoint files — mechanical follow-on;
  inventory in `PRPs/archive/` wave-2 PRP), and model-validation branches return RFC7807
  `ValidationProblem`. **The v2 client parses all three shapes** (audit wave 2,
  `src/api/error-utils.ts` `parseErrorBody`/`parseErrorText`) — new code should still emit
  the envelope. Codes added in wave 2: `email_taken` (register 409), `invalid_credentials`
  (login 401, no user-existence oracle), `invalid_request` (login 400),
  `song_name_conflict` (song create/rename 409 + the upload race catches; the common
  auto-created-name collision is avoided by auto-suffixing "name (2)", "name (3)"…).
- **Auth**: `Authorization: Bearer <jwt>` (15-min access token; `tver` claim revocation-checked).
  Refresh via httpOnly cookie `spectr_refresh` on `POST /api/auth/refresh` (rotating, 30 days).
  Query-param JWT `?t=<jwt>` accepted ONLY on `/api/versions/{id}/audio` and
  `/api/jobs/{id}/images/{kind}` (media elements cannot set headers).
- **Opaque tokens `?token=`**: version-share (`/api/v/{token}`) and room-session
  (`/api/sessions/{id}`) anon access resolves via `ResourceTokenAuth`, never the JWT `?t=` hook.
- **Cookies**: `spectr_refresh` (refresh token), `spectr_device` (anon-funnel device identity,
  HMAC; registration claims it), `spectr_anon` (durable anon actor identity, HMAC, 1 year).
- **Auth column legend**: JWT = RequireAuthorization; anon = AllowAnonymous; device = spectr_device
  cookie scope; token = opaque share/session token; admin = X-Admin-Key; dev = Development only.

**Auth**: only the two `/versions/{versionId}/sessions` routes require JWT. Every
`/sessions/{id}/*` route is `AllowAnonymous` — each handler resolves the actor itself (JWT
principal OR durable anon identity; an opaque `?token=` session/share token raises access —
never the JWT `?t=` hook) and gates per event: host authority for transport/grant/revoke/end,
scope-holder for visuals/rack.

**SSE wire** (`GET /sessions/{id}/stream`): one `event: sync` frame at connect (no `id:` line)
— `{type:'sync', chain, transport, visuals, roster, feed, snapshotSeq}` — then `event: event`
frames, each preceded by an `id: <seq>` line; the relay drops deltas with `seq <= snapshotSeq`.
Delta payload `type`s: `presence` (`state: join|leave`), `reaction`, `chat`, `status`,
`transport`, `visuals`, `rack`, `grant` (revoke echoes the same with `revokedAt` set), plus
the transient `ended` (below). All carry `at` (unix **ms**) + `seq` (`t` fields are track
seconds). 15 s of silence emits an SSE comment `: heartbeat`.

**Transient `ended`**: host POST `/end` publishes `{"type":"ended","at":<ms>}` to the room
channel — publish-only, NO WAL append, NO seq (durability comes from the DB session status;
the WAL belongs to the finalize actor). Clients fold it, render the ended state, and close
their streams.

**Finalize semantics**: `/end` only enqueues `synthesize_recap` (202). The actor SKIPS
finalize while `room:{id}:present` is non-empty, so the session stays `live` until every
stream closes (which the `ended` signal triggers). The last leaver enqueues a 3-min delayed
finalize; `GET /sessions/{id}` on a presence-empty live session enqueues an immediate one
(the lazy backstop).

## Representative contracts (the 5 UX-critical flows)

**POST /api/uploads/init** — req `{fileName, fileSize, contentType?, songId?}` → 200
`{jobId, key, uploadId, partSizeBytes, parts: [{partNumber, url}]}`. Client PUTs parts straight
to R2/MinIO, collecting ETags. Key layout `audio/{userId}/{jobId}/source{ext}`.

**POST /api/uploads/complete** — req `{jobId, key, uploadId, parts: [{partNumber, eTag}],
songId?, genreHint?, analyze?}` → 200 `{songId, versionId, jobId: Guid?}` (jobId null when
`analyze=false`). Verifies object existence before creating rows; dispatch runs the full
entitlement/abuse/verify gate chain.

**POST /api/versions** (legacy proxy upload) — multipart `file` (≤250 MB), `song_id?`,
`genre_hint?`, `analyze?` → 200 `UploadResponse {songId, versionId, jobId: Guid?}`. Dispatch
failure modes: 409 `entitlement_exhausted` / `insufficient_credits`, 403
`email_verification_required`, 429 `rate_limited`, 503 `entitlements_unavailable`.

**GET /api/jobs/{jobId}** — 200 `JobStatusDto {id, status: pending|processing|complete|failed|
awaiting_stem_mapping, currentPhase, phasePct, versionId?, songId?, errorMessage?, dispatchedAt,
startedAt?, completedAt?, failedAt?}`. Reading a failed `invalid_file` job triggers the lazy
credit reversal (idempotent).

**GET /api/jobs/{jobId}/results** — 200 `JobResultsDto {jobId, analysisId, versionId?, songId?,
songName?, finalJson (full 7/8-phase report), shareToken?, alsProject?, spectrogramUrl?,
waveformUrl?}`. Image URLs need `?t=` appended client-side.

**POST /api/reports/{jobId}/fix-rack** — no body → 202 `{status:"queued"}`; then poll
**GET** same path: 204 until the worker preset lands, then 200 `FixRackDto {presetId, name,
chain, coachMeta?, createdAt}` — `presetId` feeds the Listen rack via `?fixPreset=`.
