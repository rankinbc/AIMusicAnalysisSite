## Project Overview

- **Type:** monorepo with 5 documented parts (+2 legacy, overview-only)
- **Primary languages:** TypeScript (SPA), C# (.NET 10 BFF), Python 3.11 (worker/analysis)
- **Architecture:** SPA → BFF gateway → Postgres + Redis-queued Python worker

## Quick Reference by Part

#### frontend-v2 (web)
- **Tech:** React 19, Vite 6, TS strict, TanStack Router/Query, CSS Modules
- **Root:** `components/frontend-spectr-v2` · dev :5174
- **Docs:** [Architecture](./architecture-frontend-v2.md) · [Component Inventory](./component-inventory-frontend-v2.md) (30 routes, 136 components)

#### bff (backend)
- **Tech:** ASP.NET Core .NET 10 minimal APIs, EF Core 10 + Npgsql, Stripe.net 52
- **Root:** `components/bff` · :5000 · canonical DB schema in `src/Spectr.Data`
- **Docs:** [Architecture](./architecture-bff.md) · [API Contracts](./api-contracts-bff.md) (~198 routes, 36 endpoint files)

#### worker (backend)
- **Tech:** Python 3.11 dramatiq over Redis; Anthropic CLI/SDK/FAKE transports
- **Root:** `components/worker` · 13 actors on 4 queues (no `default`)
- **Docs:** [Architecture](./architecture-worker.md)

#### analysis (library)
- **Tech:** librosa/pyloudnorm/demucs (numpy<2.0), allin1 via Docker
- **Root:** `components/analysis` · `audio_analysis.run_pipeline()`
- **Docs:** [Architecture](./architecture-analysis.md)

#### shared (library)
- **Tech:** SQLAlchemy 2.0 mirror of the EF schema + verdict scoring authority
- **Root:** `components/shared`
- **Docs:** [Architecture](./architecture-shared.md)

Legacy (not separately documented): `components/api` (FastAPI v1), `components/frontend-spectr` (v1 SPA) — being phased out.
